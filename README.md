
# Smart Calendar AI

## Project Overview
Smart Calendar AI is a Python-based project that connects with Google Calendar and helps users manage their daily schedules.

## Features
- Google Calendar Integration
- View Upcoming Events
- Find Available Time Slots
- Schedule Meetings
- Meeting Reminders
- Meeting Conflict Detection
- Smart Meeting Time Suggestions

## Technologies Used
- Python
- Google Calendar API
- Google OAuth 2.0
- VS Code

## Python Libraries
- google-api-python-client
- google-auth-httplib2
- google-auth-oauthlib

## How to Run
1. Install required Python libraries.
2. Configure your Google Calendar API credentials.
3. Run the following command:

python main.py

## Security
Credentials and access tokens are excluded using .gitignore.
